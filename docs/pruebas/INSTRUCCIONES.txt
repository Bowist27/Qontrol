===================================================================
 COMO EJECUTAR LAS PRUEBAS AUTOMATIZADAS
===================================================================

REQUISITOS:
- Tener Node.js instalado (comando 'node' disponible).
- Tener el backend (auth-service) corriendo en localhost:8080.
- Tener el backend (audit-service) corriendo en localhost:8085.

-------------------------------------------------------------------
 OPCIÓN 1: EJECUTAR PRUEBAS ESPECÍFICAS
-------------------------------------------------------------------

Para HU09 (Logout Seguro):
    node docs/pruebas/test_hu09_logout.js

Para HU10 (Dashboard de Auditorías):
    node docs/pruebas/test_hu10_audits.js

Para HU11 (Ciclo de Vida de Auditoría):
    node docs/pruebas/test_hu11_audit_lifecycle.js

Para HU12 (Catálogo Maestro):
    node docs/pruebas/test_hu12_catalog.js

-------------------------------------------------------------------
 OPCIÓN 2: EJECUTAR TODAS LAS PRUEBAS DE LA CARPETA (MASIVO)
-------------------------------------------------------------------
Si agregas más archivos de prueba en el futuro y quieres correrlos 
todos de una vez, copia y pega este comando en tu PowerShell:

    Get-ChildItem docs/pruebas/test_*.js | ForEach-Object { 
        Write-Host "Ejecutando: $($_.Name)" -ForegroundColor Cyan
        node $_.FullName 
    }

Este comando buscará todos los archivos que empiecen con "test_" 
en esta carpeta y los ejecutará uno por uno.
